## 빠른 시작

```bash
npm install
npm run typecheck        # 타입 검사
npm test                 # 단위 테스트 (43개)
npm run validate:stages  # 스테이지 데이터 검증
npm run sim              # 밸런스 시뮬레이션
npm run sim -- S1-08 500 # 특정 스테이지 500회
```
