## 수군 원화 — 기존 원화 합성
- 새 그림을 생성하지 않고 기존 시트를 런타임에 합성한다 (`packages/web/src/naval-art.ts`).
  - 승조원: `units-v3.png`의 방패 보병·창병·궁병·책사 프레임(4포즈)을 그대로 배 위에 세움.
  - 선체 판재: `ram-v1.png` 충차 측면 판재를 잘라 반복 무늬로 채움.
  - 돛대 깃발: 충차의 청색 깃발, 뱃머리 충각: 충차의 금빛 양머리 장식.
  - 뱃전 위로 상반신만 보이도록 다리를 선체 뒤로 숨겨 "배를 타고 있음"을 분명히 했다. 방패 5개, 노 4개(포즈마다 각도가 바뀌어 노 젓기), 물보라를 덧그림.
- 4행(방패 수병·창 수병·궁 수병·지휘선) × 4포즈 아틀라스. 부대 ID/이름으로 승조원이 고정된다.
- 전장: 수군은 104px로 크게 표시, 흘수선에 앵커, 대기 중 물결에 흔들림, 이동 시 노 포즈 교대, 적 함선은 좌향, 2칸 공격은 사격 연출.
- 미리보기: `docs/naval-crews.png`, `docs/naval-battle.png`.

## 수전 전장 — 외전 T07 「장강 수군 조련」
- 신규 지형 테마 `naval`(장강 수채): 18×12, 강 한가운데 숲·구릉 섬, 북쪽 급류, 남쪽 부교, 동쪽 강안 진채.
- 아군 수군 2척이 물 위 칸에서 출진(본대·지원 부대는 서쪽 강안). 적: 몽충·투함·주가 3척 + 강안 궁병.
- 육군은 부교로 건너고 수군은 강 위에서 적선을 묶는 구조. 자동 전투 2시드 6~8턴 승리.
- 권장 Lv.11, 본편 6승 후 개방. 추천 편성: 노병 + 의술사.

## 공성 보강
- 공병(지원 병종에 추가):
  - **수리**: 인접한 아군 충차·포차·방책·성문·수송대 HP 24+지력×0.4 회복.
  - **방책**: 인접 빈 칸(평지·길·구릉·성채·다리)에 HP 70 방책 설치, 전투당 2회. 방책은 기존 성벽 원화를 재사용.
- **성문 돌파**(새 규칙 전투): 성문이 무너지면 반경 2칸 안의 직접 지휘 부대에 사기(공격 ×1.12) 2턴.
- 연출: 무너진 성문·감시탑·방책 자리에 원래 원화를 쓰러뜨린 잔해가 남음, 충차·포차 타격 시 파편과 화면 진동, 포차 탄도 잔상, 구조물 HP 표시(`30/95`).
- 코어 AI 수정: 편입 아군은 "본대만 점령 가능" 거점을 차지하지 않고 비켜선다. 아군이 거점 칸을 막아 본대가 점령하지 못하던 교착(동관)이 해소되어 시뮬레이터 동관 극한 클리어율이 71%→100%.
- 미리보기: `docs/siege-works.png`.

## 사운드 — 전부 합성음(샘플 없음)
- `packages/web/src/music.ts`: 장소 테마 10종(군영·온현 장원·낙양 성시·관문·장강·수채·숲길·공성·흉몽 궁정·들판). 5음 음계 선법, 템포, 주선율·대선율 악기, 타악 패턴, 배경층을 지정.
  - 본편 8장, 외전 지형, 맵 지형 비율 순으로 장소를 고른다.
- `packages/web/src/audio.ts`: 쟁(뜯는 현), 죽적, 이호, 뿔나팔, 편종, 북, 목탁, 징, 물·바람 소음층을 Web Audio로 합성. 간이 잔향 포함.
- 병종별 음악: 선택한 부대 계열이 모티프 층을 덧입힌다 — 기마(말발굽+나팔), 보병(행진 북+이호), 궁병(뜯는 현), 책사(편종), 공성(큰북·삐걱임), 수군(물결+뱃노래), 민중(피리). 적 차례에는 해제.
- 효과음: 병종별 선택 호출, 이동(말발굽/발소리/물살/바퀴), 공격(칼 부딪힘/화살/충차 강타/포차 발사/수상 접현), 구조물 타격 균열, 책략, 수리 망치, 성문 돌파(징+붕괴+나팔), 턴, 승리·패배.
- 헤드리스 Chromium에서 장소 10종·효과음 15종 모두 실제 출력(RMS) 확인, 나이퀴스트 초과 배음 제거.
