## 10월 2일 외전·성장 연결 완성

- 첫 특성 → 수련 특성 → 보물 인연 특성을 순서대로 해금한다. 본편과 외전의 승리 화면 모두 새 레벨·책략·특성을 안내한다. 책략은 지원 6종을 포함해 총 30종이다.
