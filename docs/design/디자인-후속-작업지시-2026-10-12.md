# 디자인 후속 작업지시 (2026-10-12)

기준 브랜치는 `main`, 기준 커밋은 `494ffca`다. 작업을 시작하기 전에 반드시 `git pull --ff-only origin main`으로 최신 개발분을 받는다.

이번 전달 범위는 **새 원화 제작**이다. 코드로 만든 연무장·활터·마장·황야·능묘는 완료됐으며, 이야기 전신 시트 9장의 크기·발선 보정과 상편 먹그림의 성인 사마의 교체도 완료됐다. 현재 코드는 이야기 시트에 9번째 칸이 있으면 그 칸을 앉은 자세로 바로 사용하고, 아직 없으면 기존 무릎 자세 원화를 임시로 사용한다.

## 공통 제작 규칙

- KOEI·넥슨 그림은 분위기 참고만 한다. 그대로 베끼거나 추출하지 않고, 직접 제작하거나 상업 이용권이 분명한 원본만 쓴다.
- 사마의는 수염과 검은 관을 갖춘 **성인 최종 모습 하나만** 쓴다.
- 그림 안에 글자가 꼭 필요하면 한글만 쓴다. 한자는 넣지 않는다.
- 인물의 얼굴·갑옷·관모·무기 색은 같은 장수의 기존 초상·흉상·이야기 시트와 통일한다.
- WebP 원본은 가장자리 잘림, 칸 사이 침범, 불필요한 바닥색 없이 납품한다. 인물·소품 시트는 RGBA 투명 배경이다.
- 새 장수를 등록하는 작업이라면 `public/officers/manifest.json`, `src/officer-models.ts`, `src/officer-factions.ts` 세 곳을 함께 고친다.

### 연의 기반 무기·탈것 고증

- 장수의 무기는 게임 보물이나 병종 기본 무기로 임의 대체하지 않고, 연의에서 해당 장수가 실제로 들고 나온 고유 무기를 우선한다. 무기 이름·형태·손잡이·날의 방향은 연의 장면, 장수 열전, 기존 대결·초상 원화를 서로 대조한다.
- 검·도는 베기, 창은 찌르기, 극·언월도·도끼는 무거운 반월 베기, 활·노는 서로 다른 투사체, 부채·법구는 바람 궤적으로 읽히게 만든다. 공격 칸의 무기 끝은 기본 방향인 오른쪽 전방으로 나가야 한다.
- 장착 보물은 고유 무기를 바꾸지 않는다. 고유 무기가 정해지지 않은 장수만 병종 기본 무기를 사용하고, 그마저 없을 때만 장착 무기를 참고한다.
- 말을 타는 장수는 연의에서 반복해서 보이는 말의 색·갈기·얼굴 무늬·안장·마구를 우선한다. 기록이 여러 가지면 본편에서 가장 자주 보이는 조합을 기준으로 고정하고, 장수마다 말 색을 임의로 공유하지 않는다.
- 말 색상과 마구는 대결 그림·전투 지도 모델·초상에서 일관되어야 한다. 기마 전투 시트의 말 몸통 크기는 기존 장료·하후돈 계통과 맞추고, 꼬리·귀·창끝은 셀 안에 둔다.
- 연의에 근거가 없는 장식, 서양식 판금 갑옷, 현대식 무기, 임의의 형광색 말은 넣지 않는다. 근거가 불명확한 세부는 절제된 시대풍으로 처리하고 검수표에 근거를 기록한다.

## 1순위 — 방석 위에 앉은 자세

이야기 전신 시트가 있는 장수 전원에게 **허리를 펴고 방석 위에 무릎 꿇어 앉은 자세**를 추가한다.

- 기존 8칸은 손대지 않고 오른쪽에 9번째 칸을 붙인다.
- 열 순서: 서기 / 걸음A / 걸음B / 말하기 / 읍 / 무릎 / 놀람 / 가리키기 / **방석에 앉기**.
- 행 순서: 앞 / 뒤 / 옆(오른쪽을 봄).
- 1280×480 시트는 셀 160×160을 유지해 1440×480으로, 2048×768 시트는 셀 256×256을 유지해 2304×768로 확장한다. 기존 8칸을 늘이거나 줄이지 않는다.
- 세 방향 모두 허리가 곧고 상체 높이가 같아야 한다. 엉덩이·무릎·접힌 다리와 방석의 접촉이 자연스러워야 하며, 서 있는 다리를 눌러 찌그러뜨린 모양이나 몸이 바닥에 묻힌 모양은 불합격이다.
- 방석은 장수보다 튀지 않는 짙은 적갈색 또는 남색으로 통일하고, 옆 방향에서는 방석 두께가 보여야 한다.
- 각 셀 위쪽 6% 이상, 아래쪽 4% 이상을 투명하게 비운다. 관모·깃털·무기·옷자락·방석이 셀 경계를 넘지 않아야 한다.
- 앞·뒤·옆의 앉은 바닥선과 인물 크기를 각각의 기존 행에 맞춘다.

## 2순위 — 실내 원화 4종

인물이 걸어 들어와 서고 앉을 수 있는 넓은 바닥을 확보한 16:9 채색 원화로 제작한다. 현재 전면 배경 규격에 맞춰 **1600×900 WebP**를 우선 사용한다. 인물, 이름, 대사, 글자는 배경에 합치지 않는다.

1. **군의용 실내**: 낮은 탁자 하나와 방석 여러 개가 실제 원화에 놓인 판. 장수 4~6명이 탁자 둘레에 앉아도 겹치지 않도록 중앙 바닥을 넓게 둔다. 지도·죽간·잔 정도만 절제해 올린다.
2. **연회장**: 낮은 잔칫상, 등잔, 병풍 또는 악사 자리가 보이되 중앙 동선을 비운다. 음식과 그릇은 시대감에 맞게 소박하게 한다.
3. **옥사**: 목제 또는 쇠창살, 돌벽, 횃불, 짚자리. 인물이 창살 앞과 안쪽에 각각 설 수 있게 깊이를 분명히 한다.
4. **관아 실내**: 정사 회의가 가능한 관아 대청. 상석과 낮은 책상, 죽간 수납, 기둥을 두고 중앙 회의 공간을 비운다.

낮·밤·비 변형은 코드에서 조명 합성이 가능하므로 우선 낮 또는 중립광 원본 한 장씩 납품한다. 파일명은 코드 등록 때 확정하되 `story-council-day-v1.webp`, `story-banquet-day-v1.webp`, `story-prison-day-v1.webp`, `story-office-day-v1.webp`를 권장한다.

## 3순위 — 마장용 말 소품

- 기수 없는 말 한 필, 마구를 갖춘 차분한 대기 자세로 그린다.
- 현재 마장 배경과 어울리는 반측면(3/4) 방향, 투명 RGBA WebP로 만든다.
- 말 전체와 꼬리·귀·고삐가 잘리지 않아야 하며, 바닥·그림자·울타리·건초는 합치지 않는다. 그림자는 코드에서 붙인다.
- 멀리서도 갈기·안장·다리 실루엣이 구분되되 장수 전신보다 시선을 빼앗지 않는 채도와 명암으로 맞춘다.
- 권장 파일명: `public/story-props/horse-idle-v1.webp`. 실제 경로와 표시 크기는 개발 연결 전에 확인한다.

## 4순위 — 기존 2·3순위 잔여 작업

### 4-1. 대결 동작 프레임

현재 4칸 대결 시트와 같은 256×256 셀, 같은 바닥선(y=230), 위·옆 여백 26px 이상을 지킨다. 인물은 오른쪽을 보고, 적으로 표시할 때 코드가 뒤집는다.

- 말 탄 장수: 휘두르기 / 찌르기 / 맞아서 뒤로 젖혀짐 / 패배 후 무릎 꿇기.
- 책사: 부채 휘두르기 / 설득 손짓 / 맞아서 뒤로 젖혀짐 / 패배 후 무릎 꿇기.
- 네 동작을 별도 1024×256 시트로 납품하는 방식을 권장한다: `public/officers/<id>-duel-actions-v1.webp`.
- 기마 장수의 패배 자세는 말과 사람이 함께 무너져 보이지 않도록, 말은 멈추고 장수가 고개와 상체를 낮추는 구도로 처리한다.
- 개발 연결 지점은 `src/duel-ui.ts`의 `animateDuel`이다. 원화가 들어오기 전의 몸 전체 기울이기 연출은 연결 후 제거한다.

### 4-2. 대결 배경 9종

기존 대결 배경과 같은 16:9 구도와 채색 밀도로 제작한다. 두 인물이 좌우에 서고 중앙에서 부딪치므로, 화면 아래 35%와 중앙을 비우고 중요한 구조물이 인물 뒤를 가르지 않게 한다.

- 일기토 5종: 눈밭 / 다리 위 / 성벽 위 / 불타는 진영 / 갈대 강가.
- 설전 4종: 오의 궁정 / 촉 승상부 / 밤 군막 / 조정 대전.
- 인물·글자·효과를 배경에 합치지 않는다. 불·눈·연기처럼 반복 애니메이션이 필요한 요소는 분리 가능한 층도 함께 납품한다.

### 4-3. 채색 초상 약 60명

- 우선순위는 **등용 가능한 장수 중 전용 채색 초상이 없는 사람 → 연의에서 자주 만나는 적장** 순이다.
- 정확한 남은 인원과 순서는 작업 시작 시 `public/portraits/manifest.json`과 `docs/art/초상-제작-목록.md`를 대조해 확정한다. 이미 등록된 초상을 다시 만들지 않는다.
- 지난 제작분과 같은 최소 512×512(권장 1024×1024) 정사각 WebP, 어두운 유화풍, 흉부 위 구도, 얼굴 중앙, 눈은 위쪽 1/3에 둔다.
- 얼굴 뒤에 이름 도장이나 글자를 넣지 않는다. 완성 후 `public/portraits/manifest.json`에 등록한다.

### 4-4. 채색 이야기 배경 5종

1600×900 WebP, 인물·글자 없는 중립광 원본으로 제작한다.

1. 병상 침실: 휘장, 침상, 약탕기.
2. 꿈 공간: 먹안개와 붉은 달, 현실과 구분되는 비현실적 깊이.
3. 별 떨어지는 오장원의 밤: 진영 위 밤하늘과 떨어지는 별. 제갈량의 마지막 장면에 맞는 절제된 분위기.
4. 요동 설원: 눈 덮인 성 밖과 거센 날씨, 인물이 설 수 있는 전경 확보.
5. 물에 잠긴 들판: 번성 수몰을 떠올릴 얕은 물과 잠긴 논밭, 이동 경로가 읽히는 구도.

### 4-5. 전투 지형 타일 8종

눈 / 모래 / 늪 / 갈대 / 대나무숲 / 시가지 골목 / 잔도 / 능묘 석상.

- 현재 전장 카메라·타일 크기·이음새에 맞춰 반복 가능한 가장자리를 만든다. 같은 지형을 이어 붙였을 때 경계선이 드러나면 안 된다.
- 이동·방어·시야·화공 보정은 그림과 별도 표로 제안한다.
- **규칙을 코드나 스테이지에 넣기 전에 개발 쪽에 먼저 알린다.** 제안 수치로 32장×난이도 클리어율 시뮬레이션을 다시 돌리고 승인한 뒤 연결한다.

## 납품·검수 순서

1. 각 묶음은 원본 WebP와 전체 시트 미리보기 PNG를 함께 검수한다.
2. 이야기 시트는 자동 측정으로 셀 침범·투명 여백·바닥선을 확인하고, 군의 장면에서 앞·뒤·옆 앉기를 실제 화면으로 본다.
3. 배경은 1366×768, 1920×1080, 휴대폰 가로 844×390에서 인물과 대화창에 가려지는 부분을 확인한다.
4. 장수 그림을 추가·교체한 뒤 `packages/web`에서 `npx tsc --noEmit`, `npx vitest run`, `npm run validate:stages`, `npx vite build`를 모두 통과시킨다.
5. 작업 묶음별로 커밋을 나눈다. 푸시 직전 다시 `git pull --rebase origin main`으로 개발 변경을 받고 충돌을 해결한다.
