## 3. 만드는 방법

- 이야기 배경은 지금처럼 코드로 그리는 아이소메트릭 장면(`story-iso.ts`)에 장면 종류를 더하면 그림 파일 없이 늘릴 수 있다. 시장·연회장·옥사·둔전·잔도처럼 소품 조합으로 되는 것부터 하는 것이 좋다.
- 채색 원화 수준의 배경(병상 침실, 꿈 공간, 오장원 밤하늘 등)은 그림을 새로 그려야 한다. 상업 배포를 생각하면 직접 그리거나, 사용권이 분명한 생성 도구로 만든 원본을 넣는다(KOEI·넥슨 그림은 쓰지 않는다).
- 전투 지형(눈·모래·늪)은 코어 규칙(`TerrainKind`)과 타일 그림을 함께 더해야 하므로, 밸런스 시뮬레이션(sim)을 다시 돌려 클리어율 기준을 확인한다.

## 진행 현황

- **코드로 만든 야외 배경 5종 (완료)**
  - 그리는 방식: 기존 야외 배경과 같은 재료(채색 풀밭 질감, 원화 나무·바위·집, 도트 소품)로 조합했다. 부족한 소품만 같은 도트 화풍으로 새로 그렸다(무기 걸이, 허수아비 표적, 과녁, 비석, 석상, 봉분, 여물통, 세로 울타리).
  - 연무장: 사열대(전각), 무기 걸이, 허수아비 표적 두 줄, 깃발, 울타리
  - 활터: 사정(정자), 과녁 네 개, 화살 상자, 소나무
  - 마장: 울타리 친 풀밭, 마구간, 건초더미, 여물통
  - 황야(서량): 모래빛 땅, 바위, 마른 나무
  - 능묘: 봉분, 비석, 돌 신도, 문관·무관 석상, 석등, 소나무
- **쓰이는 곳**
  - 수련: 연무장에서 시작, 활터·마장에서 출진
  - 도전: 관문 앞에서 시작, 연무장에서 출진
  - 보물 사냥: 마장에서 출진
  - 「원소의 묘 앞 / 무덤 앞」 장면: 능묘
  - '황야·사막·서량 벌판'이 들어간 장소: 황야
- **디자인 쪽에 남은 것**
  - 실내 배경(연회장·옥사·관아): 실내는 통째로 그린 채색 원화를 쓰고 있어서, 코드로 그리면 품질이 떨어진다. 원화가 필요하다.
  - 마장의 말: 소품으로 그릴 말 그림이 없어서 빈 마장으로 두었다.
