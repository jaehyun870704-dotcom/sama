**1차 검수 결과:** 마초·여포 일기토를 뺀 18장이 칸 정렬 불량이었다. 장면 4개를 칸과 상관없이 가운데에 몰아 그려 칸 경계에 걸쳤다. 우리 쪽에서 다시 맞췄다. **이번부터는 처음부터 칸에 맞춰 그린다.**

**대상(2차):** `sima_yi sima_lang sima_fang cao_zhen sima_shi sima_zhao meng_da jun ma_su wang_ping wei_yan gao_xiang liu_feng ma_dai guan_suo huang_quan fa_zheng chen_shi wu_ban wu_yi liao_hua zhang_yi fei_yi zhou_cang jian_yong mi_zhu sun_qian li_yan deng_zhi mi_fang ma_liang yi_ji yan_yan jiang_wan yang_yi huang_yueying zhang_bao guan_xing zhuge_jin`

**파일 (장수마다 2개):**
- `public/officers/{id}-sd-v1.webp`: 1400×280 RGBA, 칸 350×280 × 4칸(대기·한 걸음·공격·방어), 모두 오른쪽 보기.
- `public/officers/{id}-duel-v2.webp`: 1024×256 RGBA, 칸 256×256 × 4칸(대기·기세·필살·피격), 모두 오른쪽 보기.

**칸 정렬 (반드시 지킬 것):**
- 장면 하나는 **자기 칸 안 가운데**에 그린다.
- 발끝(말은 발굽)은 SD는 칸 위에서 268px, 일기토는 230px 선에 맞춘다.
- 무기·깃·꼬리가 칸 경계를 넘으면 안 된다. 긴 무기는 대각선으로 접는다.
- 납품 전에 아래 검사를 돌려 결과가 `[]`(빈 목록)인지 확인한다.
  ```
  python3 - <<'EOF'
  from PIL import Image;import glob
  for pat,cell in (('*-sd-v1.webp',350),('*-duel-v2.webp',256)):
    for f in sorted(glob.glob('packages/web/public/officers/'+pat)):
      im=Image.open(f).convert('RGBA');a=im.split()[3].load();w,h=im.size
      bad=[k for k in range(1,w//cell) if sum(1 for x in (k*cell-1,k*cell) for y in range(h) if a[x,y]>16)>4]
      print(f.split('/')[-1],bad)
  EOF
  ```

**장수 하나가 끝날 때마다 같은 커밋에서:**
1. `src/officer-models.ts`의 `UNIFIED_SD_IDS`에 id를 더한다. 연결은 이것으로 끝난다.
2. `public/officers/manifest.json`의 그 장수 항목을 `"battle":{"sd":{"sheet":"{id}-sd-v1.webp","cell":[350,280],"rows":1}}`, `"duel":"{id}-duel-v2.webp"`로 바꾼다.
3. 옛 그림을 `git rm`한다. 대상은 `{id}-battle-*-v1.webp`와 `{id}-duel-v1.webp`다.
4. 사마의·사마랑·사마방·조진은 옛 묶음 시트(`officer-battle-sima-v2.webp`, `officer-battle-wei-v2.webp`)에도 들어 있다. 묶음에 든 장수가 모두 끝나면 그 시트를 지우고, `officer-models.ts`의 `legacy`·`duelRows`에서 해당 줄을 뺀다(못 하면 목록만 남겨 달라).
5. `npx vitest run packages/web/test/officer-models.test.ts packages/web/test/npc-roster.test.ts`가 통과해야 한다.

**화풍:** 1차 10명과 같게 한다. 머리 큰 SD, 굵은 외곽선, 연의 고유색·고유 무기, 장수마다 정해진 말 색. 진화 단계별 그림은 만들지 않는다(한 번 만든 모습 그대로).
