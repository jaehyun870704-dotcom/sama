# 06. 초상 · 대화 흉상

- **대상:** 장수 초상(정보 창·인물열전·명단), 대화창 흉상(표정 3가지) 그림 묶음
- **파일:** `packages/web/public/portraits/<이름>.webp`, `officers/<id>-bust-v1.webp`

## 규격

### 초상
| 항목 | 기준 |
|---|---|
| 크기 | **512×512 이상**, 정사각 |
| 화풍 | 어두운 유화풍. 배경은 어두운 갈색·먹색 그라데이션 |
| 배경 밝기 | 위쪽 8% 띠의 평균 밝기 **60 이하** (0~255) |
| 얼굴 위치 | 가로 가운데, 눈높이는 위에서 1/3 |
| 구도 | 가슴 위 반신. 손·무기가 얼굴을 가리지 않는다 |

### 대화 흉상
| 항목 | 기준 |
|---|---|
| 크기 | **3072×1024**, 1024×1024 칸 3개 |
| 칸 순서 | 평상 → 분노·결의 → 미소 (기존 파일과 같은 순서) |
| 배경 | 투명 |
| 화풍 | 초상과 같은 사람으로 보여야 한다(옷·관·수염·흉터) |

## 원칙
- 대화창에서는 초상·흉상이 번갈아 나온다. 화풍과 밝기가 다르면 바로 튄다. 새 초상은 기존 초상 3~4장과 나란히 놓고 톤을 맞춘다.
- 애니메이션풍·밝은 배경·낮은 해상도는 쓰지 않는다.

| 밝은 배경 4장 (조창·만총·문빙·원담) | 어둡게 바뀜. 위쪽 밝기 27~34 |
| 대화 흉상 | 14장, 모두 3072×1024 |

## 남은 위반

> **최신 (c320316):** 512px 미만 초상 11장을 다시 그려 166장 모두 512px 이상이다. 살 남짓으로 다시 그려졌다.
> - **남은 참고:** 새 초상 중 한신(위쪽 밝기 80)과 신장수 4장(62~71)은 배경이 기준(60 이하)보다 조금 밝다. 전장 풍경이 배경에 들어가 있다. 대화창에서 크게 튀지는 않는다.

- 손권 초상(323px)은 자주 나오는 인물이라 먼저 고치기를 권한다.

## 검수 방법
1. `portraits/*.webp` 전부의 크기·정사각 여부를 잰다.
2. 위쪽 8% 띠의 평균 밝기를 잰다(60 이하).
3. 바꾼 초상과 이웃 초상 12장을 한 장에 모아 톤을 눈으로 비교한다.
