# 06. 초상 · 대화 흉상 · 소년 사마의

- **대상:** 장수 초상(정보 창·인물열전·명단), 대화창 흉상(표정 3가지), 소년 사마의 그림 묶음
- **파일:** `packages/web/public/portraits/<이름>.webp`, `officers/<id>-bust-v1.webp`
- **연결 코드:** `packages/web/src/officer-art.ts`, `faces.ts`, `youth.ts`

## 규격

### 초상
| 항목 | 기준 |
|---|---|
| 크기 | **512×512 이상**, 정사각 |
| 화풍 | 어두운 유화풍. 배경은 어두운 갈색·먹색 그라데이션 |
| 배경 밝기 | 위쪽 8% 띠의 평균 밝기 **60 이하** (0~255) |
| 얼굴 위치 | 가로 가운데, 눈높이는 위에서 1/3 |
| 구도 | 가슴 위 반신. 손·무기가 얼굴을 가리지 않는다 |

### 대화 흉상
| 항목 | 기준 |
|---|---|
| 크기 | **3072×1024**, 1024×1024 칸 3개 |
| 칸 순서 | 평상 → 분노·결의 → 미소 (기존 파일과 같은 순서) |
| 배경 | 투명 |
| 화풍 | 초상과 같은 사람으로 보여야 한다(옷·관·수염·흉터) |

### 소년 사마의 (S1-01~S1-03)
- 같은 장(그 사이 행군 전투 포함)에서는 사마의 그림이 모두 소년으로 바뀐다. 이름·능력치·유닛은 그대로 사마의다(`youth.ts`의 `setStoryEra`).
- **나이:** 열 살 남짓. 얼굴이 둥글고 목이 가늘며, 관을 쓰지 않고 머리를 묶는다.
- **어른 사마의와 이어지는 표식:** 초록 머리끈, 흰 깃의 녹색 겉옷, 흰 깃털 부채.
- **파일 4종 (모두 같은 아이로 보여야 한다):**

| 파일 | 내용 |
|---|---|
| `sima_yi_young-bust-v1.webp` | 흉상 |
| `sima_yi_young-battle-strategist-v1.webp` | 지도 그림, SD |
| `officer-battle-sima-v2.webp` 1행 | 대결 그림 |
| `sima_yi_young-story-v1.webp` | 이야기 장면 |

## 원칙
- 대화창에서는 초상·흉상이 번갈아 나온다. 화풍과 밝기가 다르면 바로 튄다. 새 초상은 기존 초상 3~4장과 나란히 놓고 톤을 맞춘다.
- 애니메이션풍·밝은 배경·낮은 해상도는 쓰지 않는다.

## 검수 방법
1. `portraits/*.webp` 전부의 크기·정사각 여부를 잰다.
2. 위쪽 8% 띠의 평균 밝기를 잰다(60 이하).
3. 바꾼 초상과 이웃 초상 12장을 한 장에 모아 톤을 눈으로 비교한다.
4. 소년 사마의: S1-01 전투·브리핑에서 화면에 쓰인 그림이 모두 `sima_yi_young*`인지, S1-04에서는 하나도 없는지 확인한다(요소의 `style`·`src` 검색).
