# 사마의전 디자인 가이드 — 최종본

- **기준:** sama-game main `5db55b3`
- **확정일:** 2026-10-10
- **측정 화면:** PC 1366×768, PC 1920×1080, 휴대폰 가로 844×390

이 문서는 그림과 화면을 새로 만들거나 고칠 때 따르는 최종 기준이다. 요소별 파일(00~07)에 남은 수정 이력과 지난 측정값은 참고 기록이다. 서로 다르면 이 문서를 따른다.

---

## 1. 공통 원칙

1. **화풍은 두 가지다.**
   - **작게 보이는 화면은 SD 비율이다.** 전투 지도, 진영 걷기, 장 브리핑의 인물이 여기에 든다. 머리가 크고 외곽선이 굵다.
   - **크게 보이는 화면은 실제 비율의 어두운 유화풍이다.** 일기토·설전, 대화 흉상, 초상이 여기에 든다.
   - 한 화면 안에서 두 화풍을 섞지 않는다.
2. **같은 줄에 서는 것은 키와 발끝이 같다.** "비슷해 보이면 된다"가 아니라 측정값으로 판단한다.
3. **칸 밖으로 나가지 않는다.** 그림판의 각 칸은 독립된 그림이다. 옆 칸 조각이 비치거나 칸 경계에서 잘리면 불합격이다.
4. **배경은 투명하다.** 지도 그림과 대결 그림은 완전 투명이다. 배경을 칠하는 것은 초상과 보물뿐이다.
5. **파일 이름과 칸 순서는 코드와의 약속이다.** 바꾸면 코드 연결도 같이 고친다(`officer-models.ts`, `painted-troops.ts`, `complete-troops.ts`, `treasure-art.ts`). 여러 줄 그림판은 줄 순서를 바꾸지 않는다.
6. **진영 색은 고정이다.** 아군 파랑, 적 빨강, NPC 우군 초록이다. 그림의 옷 색과 겹치면 발밑 원과 이름표로 구분한다.
7. **화면을 가리지 않는다.** 정보 상자는 플레이어가 움직일 유닛과 가야 할 목표를 덮지 않는다.

## 2. 전투 화면 UI

- **대상:** 전투 지도(`#map`), 승리·패배 조건(`#map-objective`), 장수 카드(`#unit-hud`), 안내 줄(`#tile-info`), 명령 단추(`#action-dock`), 첫 전투 안내(`#coach`), 전투 대사 띠(`#battle-line`)
- **코드:** `main.ts`, `style.css`, `battlefield.ts`(카메라·목표 표시), `battle-conditions.ts`(조건 문장·목표 지점), `stretch.ts`(넓은 전장·목표 칸 모양)

### 2-1. 배치

| 항목 | 기준 |
|---|---|
| 지도 높이 | 1366×768 **551px**, 1920×1080 **861px**, 844×390 **294px**. 위아래에 레일(띠)을 두어 지도를 줄이지 않는다 |
| 승리·패배 조건 | 지도 왼쪽 위의 접히는 상자다. 전투 시작에 펼치고, 장수를 처음 고르거나 8초가 지나면 한 줄 꼬리표 `◇ 목표 …`로 접는다. 꼬리표를 누르거나 O 키로 다시 펼친다. 목표가 바뀌면 6초 동안 펼친다 |
| 범례 | 이동 가능·적 시야·목표 범례는 승리 조건 상자 안에 둔다. 지도 구석에 따로 두지 않는다 |
| 장수 카드·명령 단추 | 지도 위에 띄운다. 고른 장수와 노리는 대상을 덮으면 카메라를 밀어 유닛을 꺼낸다 |
| 대사 띠·첫 전투 안내·승리 조건 | 아군을 덮으면 반대쪽으로 옮긴다. 대사 띠는 위↔아래, 안내와 승리 조건은 왼쪽↔오른쪽이다 |
| 겹침 허용 | 아군·편입 아군 유닛의 몸통 가운데는 승리 조건이 접힌 뒤 **어떤 상자에도 덮이지 않는다** |
| 휴대폰 가로 | 장수 카드는 대사 띠가 보일 때 숨긴다. 첫 전투 안내 폭은 최대 260px(화면의 42%)이다 |

### 2-2. 목표 지점 표시

| 항목 | 기준 |
|---|---|
| 깜박임 | 위치 목표(탈출·도착·점령)가 있으면 전투 시작과 목표가 바뀔 때 그 칸을 **6초 동안 깜박인다**. 차례 목표는 지금 단계의 지점만 깜박인다 |
| 색 | 탈출 **청록**, 도착 **노랑**, 점령 **주황** |
| 이름표 | 누가 어디로 가는지 쓴다. 예: `조조 탈출 / 야곡 출구 ▼`, `사마의·사마랑 탈출 / 남문`, `점령 · 중앙 성채`. 화면에서 글자가 16px 아래로 줄지 않는다 |
| 이름표 위치 | 칸 위에 단다. 지도 위·아래 끝(4줄 안)의 목표는 칸 옆 지도 안쪽에 `◀`·`▶`로 단다. 작은 지도·대사 상자에 가리지 않게 하기 위해서다 |
| 카메라 | 목표가 화면 밖이면 0.6초에 걸쳐 그쪽으로 가서 약 2.6초 머문 뒤 돌아온다. 돌아온 뒤 아군이 상자 밑에 있으면 다시 꺼낸다 |
| 카메라 예외 | 플레이어가 화면을 끌면 돌아오지 않는다. 전투 연출 중이거나 다른 전투로 넘어가면 카메라를 옮기지 않는다 |
| 상자 비킴 | 목표를 비추는 동안 승리 조건 상자가 목표 칸이나 이름표를 덮으면 반대쪽으로 옮긴다. 그래도 덮으면 접고, 꼬리표마저 덮으면 깜박임이 끝날 때까지 감춘다 |
| 가야 할 장수 | 탈출·도착해야 하는 장수는 전투 내내 **머리 위 꼬리표**(`탈출` 청록 / `도착` 노랑), **발밑 고리**, **같은 색 이름표**를 단다. 이미 도착한 장수는 꼬리표를 뗀다 |

### 2-3. 목표 칸 모양

넓은 전장(연의 지도 1.5배)으로 늘릴 때 코드가 목표 칸을 다시 놓는다(`shapeGoals`). 칸은 **띄우지 않고 붙인다**.

| 목표 | 모양 |
|---|---|
| 탈출 지점(출구·성문·관문) | **6칸**(3×2 또는 2×3). 지형이 안 되면 2×2, **최소 4칸**. 함께 탈출할 장수가 모두 설 수 있어야 한다 |
| 남문(S1-02) | 성문 3칸 + 바로 안쪽 3칸 = 6칸 |
| 합류·도착 지점 | 지도와 같은 비율로 넓힌다. S2-11 합류 지점 42칸, S2-13 합류 지점 36칸, S2-08 조휴 진영 25칸 |
| 상륙 지점(S3-07) | 물길 2칸 한 줄 |
| 점령 목표 | 원래 크기(가로×세로)로 붙인다 |
| 지형이 바뀌는 지역 | 부교·다리·수문 길·홍수 지역은 빈틈없이 채운다. 다리 가운데가 물로 남으면 안 된다 |
| 표시용 같은 지역 | 같은 칸을 이름만 달리 적은 지역(`objective` 등)은 같은 자리로 함께 옮긴다 |

### 2-4. 승리·패배 조건 문장

| 규칙 | 예 |
|---|---|
| 승리 조건이 여럿이면 아무거나 하나만 이루면 된다. **"또는"**으로 잇는다 | `적 7부대 격퇴 또는 위연 격퇴` |
| 차례로 해야 하면 `→`로 잇고 끝에 `(차례로)`를 붙인다 | `고수 격퇴 → 조비가 북쪽 출구까지 탈출 (차례로)` |
| 탈출은 누가 어디까지 가는지 쓴다 | `조조가 야곡 출구까지 탈출` |
| 같은 곳에 여럿이 모두 가야 하면 한 문장으로 쓴다 | `사마의·사마랑이 모두 남문까지 탈출` |
| 한 명만 가면 되면 이렇게 쓴다 | `A·B·C 중 한 명이 합류 지점에 도달` |
| 점령은 하는 방법을 쓴다 | `중앙 성채 점령(아군을 그 칸에 세우고 '거점 확보' 명령)` |
| 대화·사건 조건은 언제 나오는지와 그 뒤 새 목표를 괄호로 쓴다 | `호로곡 비(둘이 합류한 뒤 7턴 버티면 내림 · 그 뒤 서쪽 출구 탈출이 새 목표) 마치기` |
| 출구 이름은 지도에 쓰인 이름과 같게 한다 | 야곡 출구(S1-09), 북쪽 고개(S1-10), 서쪽 출구(S2-13), 동남쪽 출구(S3-05) |
| 진행은 끝에 붙인다 | `✓`, `(남은 3)`, `(0/7)`, `(0/8턴)` |

### 2-5. 원칙
- 지도가 주인공이다. 지도 위에 남기는 정보는 작고, 접히고, 비켜 선다.
- 늘 볼 필요가 없는 정보(승리 조건 전문)는 접는다. 왼쪽 "전투 목표" 패널에는 전문을 항상 둔다.
- 목표는 "어디로"만이 아니라 "누가"까지 보여야 한다.

## 3. 메뉴 화면 · 글꼴 · 색

### 3-1. 색 (고정)

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| `--ink` | `#191e20` | 기본 어두운 바탕 |
| `--gold` | `#c8a772` | 강조선, 제목 장식, 선택 테두리 |
| `--paper` | `#eee3c9` | 밝은 종이색 글자·카드 |
| 화면 바탕 | `#101b1d` / `#151a1b` | `body` 배경 |
| 본문 글자 | `#dddccf` / `#e1dac8` | 일반 글 |
| 목표 표시 | 탈출 `#6ff5c8`, 도착 `#ffe27a`, 점령 `#ffb04a` | 전투 지도의 목표 칸·꼬리표 |
| 진영 | 아군 파랑, 적 빨강, NPC 우군 초록 | 표식·이름표·명단 |

- 새 색은 위 토큰에서 만든 값만 쓴다. 순수 흰색(`#fff`)과 순수 회색은 쓰지 않는다.
- 형광이나 채도 높은 색은 진영 표식, 목표 표시, 효과에만 쓴다.

### 3-2. 글꼴

| 용도 | 글꼴 |
|---|---|
| 본문 | `'Malgun Gothic','Apple SD Gothic Neo',sans-serif`, 기본 14px |
| 제목·이름·대사 장식 | `LocalSerif`(바탕) → `'Noto Serif KR'` → `serif` |
| 숫자 강조 | `Georgia, serif` |

- 장식 글꼴(바탕)은 제목과 이름에만 쓴다. 긴 설명은 고딕으로 쓴다.

### 3-3. 글자 크기 배율 `--fs`

| 조건 | 값 |
|---|---|
| 기본 | 1 |
| 마우스 + 1200×680 이상 | 1.08 |
| 마우스 + 1500×820 이상 | 1.15 |
| 마우스 + 2000×1100 이상 | 1.3 |
| 터치 + 1000×700 이상 | 1.08 |

- 글자 크기는 `calc(Npx*var(--fs,1))`로 쓴다. 고정 px를 쓰지 않는다.
- 최소 크기는 본문 12px, 휴대폰 가로의 보조 설명 11.5px이다.

### 3-4. 줄바꿈과 배치
- 한국어는 낱말 단위로 줄바꿈한다(`word-break:keep-all; overflow-wrap:break-word`).
- 메뉴 창의 "← 본영" 줄은 창 아래에 붙어 늘 보인다(높이 600px 이상 화면).
- 글자 자르기(`line-clamp`, `ellipsis`)는 전문을 다른 곳에서 볼 수 있을 때만 쓴다.

## 4. 병종 그림 (전투 지도)

- **파일:** `troops-four-stage-*.webp`, `troops-single-stage-*.webp`
- **코드:** `painted-troops.ts`, `troops.ts`, `complete-troops.ts`

### 4-1. 그림판

| 종류 | 크기 | 칸 |
|---|---|---|
| 4단계 계통 | **1120×896** | 4열(대기·이동·공격·피격) × 4행(1~4단계), 칸 280×224 |
| 1단계 단독 | **1120×224** | 4열 × 1행 |
| 옛 규격 | 1400×1120, 1400×280, 1264×1244, 1448×1086 | 유지만 하고 새로 만들지 않는다 |

- 배경은 완전 투명이다. 그림은 칸 경계에서 사방 **8px 이상** 띄운다.

### 4-2. 키 (게임 자르기 규칙으로 잰 대기 자세 높이)

| 몸집 | 키 | 해당 |
|---|---|---|
| 보통(`foot`) | **154** (±4), 4단계는 166 이하 | 보병·궁병·노병·책사·기병 등 대부분 |
| 대형(`large`) | **176~184**, 계통마다 하나로 고정 | 중기병, 상병(코끼리), 전차, 포차, 단독 충차, 정란, 개마무사 |

- 몸집은 코드가 그림 폭으로 짐작하지 않는다. 그림판마다 정해 둔다. 대형 계통을 새로 넣으면 `LARGE_BODY_SHEETS`에 시트 id를 추가한다.
- 같은 계통 안에서 단계가 오를수록 키가 줄면 안 된다.
- 폭은 키와 무관하다. 무기가 길면 넓어도 된다(칸 안에 들어오면 된다).

### 4-3. 화풍
- SD 비율, 굵은 외곽선이다. 같은 계통 안에서 채도가 같다.
- 단계가 오르면 장비(갑옷·투구·장식)로 차이를 보인다. 몸을 키워서 보이지 않는다.

## 5. 장수 지도 그림

- **파일:** `officers/<id>-battle-<병종>-v1.webp`, `officer-battle-*.webp`
- **코드:** `officer-models.ts` (`officerManifest`, `officerFit`)

### 5-1. 그림판

| 종류 | 크기 | 칸 |
|---|---|---|
| 표준 | **1120×224** | 4열(대기·이동·공격·피격) × 1행, 칸 280×224 |
| 4단계 진화형 | 1120×896 | 4열 × 4행 |
| 옛 규격 | 1400×280, 1400×1120, 1024×1024 | 유지만 한다 |

- 배경은 완전 투명이다. 칸 경계에서 사방 8px 이상 띄운다.
- 파일 이름의 병종(`battle-cavalry` 등)은 `officerManifest`의 병종과 같아야 한다.

### 5-2. 크기

| 분류 | 키 | 폭(키 154 기준) |
|---|---|---|
| 도보 장수 | **154** (±2) | 140 이상 |
| 말 탄 장수 | **154** (±2) | 170 이상. 말 몸통이 기존 기병 장수(장료·하후돈)와 같은 크기 |
| 창을 위로 세운 기병 장수 | **184** (창끝 포함) | 말 몸통이 기존 기병 장수와 같아지도록 맞춘다 |
| 중기병 장수 | 176~180 | 제한 없음 |

- 창을 세운 기병 장수는 `RAISED_SPEAR_RIDERS`에 등록한다(지금 맹염·비연·장패·조휴·조상). 새로 그리면 이 목록에 넣는다.

### 5-3. 화풍
- 병종 그림과 같은 SD 비율이다. 같은 병종 병사보다 장식(망토·투구 깃·색 띠)이 화려해 한눈에 장수로 보여야 한다.
- 장수 고유색(관우 초록, 여포 붉은 깃 등)은 대결 그림·초상과 같게 한다.
- 지도에서 장수는 "같은 병종 병사 + 알아볼 표식"이다. 몸 크기로 구분하지 않는다.

### 6-3. 화풍과 규칙
- 실제 비율, 어두운 유화풍이다. 같은 장수의 초상·흉상과 옷 색·무기가 같아야 한다.

- **누가 무엇을 하는가**
  - 무력이 지력 이상인 장수는 일기토만 한다.
  - 지력이 무력보다 높은 장수는 설전만 한다.
  - 연의 맞수(`HISTORIC_DUELS`)와 S1-04 꿈속 세 맞수는 성향과 상관없이 정해진 대로 한다. 사마의–왕평 설전, 사마의–위연 설전, 사마사–맹염 일기토가 여기에 든다.

## 12. 검수 방법 (요약)

1. **전투 화면**
   - 화면 크기 3가지에서 전투 33곳을 연다.
   - 아군 유닛 화면 좌표(`field.unitScreenPoints`)를 지도 위 상자 사각형과 비교한다. 시작 직후와 8초 뒤(승리 조건이 접힌 뒤) 두 번 잰다.
   - 목표 지점은 S1-09(화면 밖 목표), S1-02·S3-07(휴대폰에서 상자와 겹치는 자리), S2-02(지도 위 끝 목표)에서 깜박임, 카메라, 이름표 위치를 본다.
2. **그림 키**
   - 게임 자르기 규칙(`alphaCutoff`·`fit`·`body`)으로 대기 프레임의 불투명 높이를 잰다.
   - 같은 계통, 같은 분류끼리 일람표로 나란히 놓고 비교한다.
3. **대결:** 62명을 같은 발끝 선에 세운 일람표를 만들고, 키 ±8%와 발끝을 확인한다.
4. **초상:** 크기·정사각 여부와 위쪽 8% 띠 밝기를 잰다.
5. **보물:** 판을 272×272로 잘라 칸마다 가장자리 12px 띠와 떨어진 조각을 확인한다.
6. **메뉴:** 모든 탭·필터를 눌러 잘림(`scrollWidth>clientWidth`), 화면 밖, 깨진 그림, 콘솔 오류, 404를 본다.
