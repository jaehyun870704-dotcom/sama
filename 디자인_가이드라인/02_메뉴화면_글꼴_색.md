# 02. 메뉴 화면 · 글꼴 · 색

- **대상:** 본영 메뉴 창 9개(본영, 보물, 인물열전, 연구, 병종 진화표, 천명, 퀘스트, 신장수, 저장), 대화 상자(`dialog`), 공통 글꼴과 색
- **코드:** `packages/web/src/style.css`

## 규격

### 색 (기존 값 고정)
| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| `--ink` | `#191e20` | 기본 어두운 바탕 |
| `--gold` | `#c8a772` | 강조선, 제목 장식, 선택 테두리 |
| `--paper` | `#eee3c9` | 밝은 종이색 글자·카드 |
| 화면 바탕 | `#101b1d` / `#151a1b` | `body` 배경 |
| 본문 글자 | `#dddccf` / `#e1dac8` | 일반 글 |
| 진영 | 아군 파랑, 적 빨강, NPC 우군 초록 | 표식·이름표·명단 |

- **새 색 추가 규칙:** 위 토큰에서 만든 값만 쓴다. 순수 흰색(`#fff`)이나 순수 회색은 쓰지 않는다.

### 글꼴
| 용도 | 글꼴 |
|---|---|
| 본문 | `'Malgun Gothic','Apple SD Gothic Neo',sans-serif`, 기본 14px |
| 제목·이름·대사 장식 | `LocalSerif`(= 바탕 `Batang`) → `'Noto Serif KR'` → `serif` |
| 숫자 강조 | `Georgia, serif` |

### 글자 크기 배율 `--fs`
| 조건 | 값 |
|---|---|
| 기본 | 1 |
| 마우스 + 1200×680 이상 | 1.08 |
| 마우스 + 1500×820 이상 | 1.15 |
| 마우스 + 2000×1100 이상 | 1.3 |
| 터치 + 1000×700 이상 | 1.08 |

- 모든 글자 크기는 `calc(Npx*var(--fs,1))`로 쓴다. 고정 px를 쓰지 않는다.
- 최소 크기: 본문 12px, 보조 설명 11.5px(휴대폰 가로)

### 줄바꿈과 배치
- 한국어는 낱말 단위로 줄바꿈한다(`word-break:keep-all; overflow-wrap:break-word`). "아직 배우지 않았 / 다."처럼 낱말이 끊기면 불합격이다.
- 메뉴 창의 "← 본영" 돌아가기 줄은 창 아래에 붙어 늘 보여야 한다(높이 600px 이상 화면).
- 글자를 `line-clamp`나 `text-overflow:ellipsis`로 자르는 것은 전투 화면 한 줄 안내(`#tile-info`)처럼 전문을 다른 곳에서 볼 수 있을 때만 쓴다.

## 원칙
- 먹(어두운 청록·검정)과 금(황동)으로 짜인 동양 고서 느낌을 유지한다. 형광·채도 높은 색은 진영 표식과 효과에만 쓴다.
- 장식 글꼴(바탕)은 제목과 이름에만 쓴다. 긴 설명은 고딕으로 쓴다.

## 현재 상태 (008b4db)
본영 메뉴 9화면을 탭과 필터까지 모두 눌러, 화면 크기 3가지(1366×768, 1920×1080, 844×390)에서 검사했다.

| 검사 | 결과 |
|---|---|
| 글자 잘림 | 0 |
| 화면 밖 요소 | 0 |
| 깨진 그림 | 0 |
| 요소 겹침 | 0 |
| 콘솔 오류 | 0 |
| 404 | 0 |

## 남은 위반
없음.

## 검수 방법
1. 화면 크기 3가지에서 각 메뉴의 모든 탭·필터를 눌러 본다.
2. 각 요소마다 아래를 검사한다.
   - `scrollWidth > clientWidth`, `scrollHeight > clientHeight` (잘림)
   - 화면 밖 위치
   - 그림의 `naturalWidth==0` (깨짐)
3. 콘솔 오류와 네트워크 404가 없는지 확인한다.
